# Garmin 商店文案

此目录仅维护商店标题、说明和更新日志，不修改表盘运行时语言。

- 墨刻：表盘及设置保留简体中文、英文，其他手表语言回退英文。
- Retro World：表盘内容保持英文；沿用原有中英文设置，不发布新的运行时国际化二进制。
- 商店：覆盖编辑器实际提供的全部 28 个语言选项，包括两种葡萄牙语。

`copies.json` 是网页填写定稿；每种语言包含 `title`、`description`、`whatsNew`。`source.json` 为英文源文案，`translations.json` 保存浏览器取得的翻译，`overrides.json` 保存人工校订。`prepare.py` 导入并校验标题 50 字符、说明及更新日志 4000 字符上限；规范术语并移除翻译页面的读音转写。

发布前逐一切换网页的 28 个语言页，核对三项值与定稿一致。免费、隐私、区域、评论通知及设备迁移设置保持原值。墨刻 1.2.0 的描述及更新日志与新包一起提交；Retro World 文案继续对应已公开的 2.1.0。
