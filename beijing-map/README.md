# 北京全离线导航 · 本能 3 Solar · v0.3 试用版

适用 **Garmin Instinct 3 Solar 45 / 50 mm**。这是独立设备应用，手表端看图、定位、搜索、算路、轨迹显示均不需要手机或网络。真表的卫星定位、罗盘、FIT 内容、耗电与长期稳定性仍待实测；验证证据见包内 JSON 和模拟截图。

## 新版功能

- UP/DOWN 切换两个 Tab：地图页与手表数据页，底部两点标示当前页。
- 右上副屏同时显示 GPS 定位质量格、本次记录计时、电池图标及百分比。GPS 格使用 Garmin 定位质量分级（良好 4 格、可用 3 格、较差 1 格、无有效定位 0 格），不是每颗卫星的信噪比。地图仍然北向朝上。
- 数据页显示手表本地时间（时分）、实时心率、今日步数、今日距离、电量、本次轨迹距离。今日距离来自 Garmin 活动监测接口；轨迹距离是本应用按有效 GPS 样本累计的估计，二者含义不同。无数据时显示 --。
- 记录计时从获得定位并成功开始活动时起算，切换页面或打开菜单继续计时；保存后冻结，查看旧轨迹时恢复保存的时长，开始新轨迹清零。旧版轨迹没有保存时长，显示 00:00:00。

- 打开应用自动请求 GPS；定位成功后跟随当前位置。未定位或定位过期时，右上副屏显示空心信号格；北京市中心底图不代表你已在那里。
- 有方向数据时显示方向箭头；否则显示定位圆点。箭头主要表示 GPS 行进方向，静止时是否随手腕旋转取决于设备是否提供罗盘方向。地图始终北向朝上。
- 获得有效定位后自动开始步行活动记录。菜单可结束并保存、开始新轨迹、查看上次轨迹；正常退出也会保存。
- 地图显示简化的已走轨迹，超过点数预算会逐步简化以保留起点和全程概貌；完整活动由 Garmin FIT 录制接口负责。
- 内置约 9.2 万条 OSM 地点、道路和部分地址记录。支持完整拼音前缀检索，结果显示中文；输入控件能提供中文时也支持中文片段检索。
- 在手表上离线计算步行推荐路线，显示粗线、剩余距离与偏离提示；可以停止导航、恢复上次目的地并离线重算。

## 安装

1. 用 USB 连接手表，打开手表存储。
2. 将包内 **BeijingMap-Instinct3Solar.prg** 复制到手表的 **GARMIN/APPS** 目录。只复制 PRG，不必另外复制地图或源码。
3. 安全弹出并断开手表，打开应用列表中的 **Beijing Offline Map**。
4. 首次到室外开阔处等 GPS 定位。信号格填充表示取得定位，计时开始递增表示正在记录；圆点或箭头才代表有效当前位置。

从旧版升级时使用同名 PRG；应用 ID 保持一致。若 Mac 没有显示手表存储，可用支持该手表 USB 模式的文件传输工具或 Windows 电脑。侧载包约 17.4 MiB，需要手表有足够空闲存储。

## 操作

主地图保留底图、比例尺和导航信息；右上圆圈是手表的硬件副屏。

- **UP / DOWN**：在地图、数据两个 Tab 间循环切换。
- 地图页 **GPS / START**：打开地图操作菜单；UP/DOWN 选择放大、缩小或平移方向，GPS 确认一次操作并返回地图。也可从长按 MENU → 地图缩放／平移进入。
- **长按 MENU**：GPS 跟随、离线地址搜索、轨迹控制、十六区切换、导航控制、帮助。
- **BACK**：数据页返回地图；地图页结束应用并保存。菜单、搜索与算路界面中返回或取消。

应用新增 Sensor 权限，仅用于读取手表支持的实时心率；没有增加联网权限。佩戴不稳、心率传感器关闭或尚未取得读数时显示 --。切页不会中断 GPS 与轨迹记录，正常退出会关闭传感器监听。

### 搜索并导航

1. 长按 MENU → **离线地址搜索**。
2. 按 GPS 打开手表输入控件，使用 UP/DOWN 选字符，GPS 输入，完成后选择 **OK**。
3. 输入完整拼音前缀，例如 **tiananmen**、**tiantangongyuan**、**yiheyuan**。不支持拼音首字母简写。五键手表输入较慢，可复用上次的输入文字。
4. 从最多 20 条中文结果中选择目标。结果旁的距离是相对当前位置的直线距离；未定位时相对浏览中心。
5. 选择 **开始步行导航**。算路需先取得有效 GPS；算路过程全部在手表本地完成。
6. 地图上粗实线是推荐路线，细底图是道路，虚线是已走轨迹。偏离后可通过搜索重新选择目的地计算路线。

## 路线的实际范围

- 使用真实 OSM 节点连接公共可步行道路、服务道路、步道和台阶等，不会仅因两条线在屏幕上交叉就连成路口。
- 当前数据约 48 万个路网节点，按 2 公里单元建立分层路网。算法生成可连通的步行推荐路线，**不保证全市最短，可能绕行**。例如数据检查中天安门到天坛的分层路线约 7.3 公里，而原始路网的最短路线约 4.5 公里。
- 起终点接入 250 米内最近的路网节点；地点坐标与实际入口可能有差距。不会把 GPS 到道路之间的直线冒充可走路径。“接近路线终点”也不等于已到达建筑入口。
- 未连通、无可用道路、路线过于复杂或超出计算预算时会报错，需选择中途地点分段。轨迹点、地图简化和 GPS 误差均可能影响显示。
- 地点库不是全量门牌地址库，部分地点和地址缺失。没有实时交通、临时封路、语音/震动转弯提示或偏离后自动重算；节点门禁及条件通行标签未完整处理，实际通行以现场为准。
- GPS 和记录只在应用运行期间工作。正常退出会保存；强制断电等异常情况下，最近未落盘的数据仍可能丢失。Garmin 平台是否同步活动取决于手表和 Connect 的设置，应用自身不请求网络权限。

## 数据与实现

数据为 Geofabrik 的北京市行政区域 OSM 提取，时间 **2026-10-25T21:21:21Z**，采用 WGS84。覆盖北京市十六区已收录路网，地图道路约 12 米、步道约 8 米的简化容差；不是实测地图或完整通行保证。

地图采用分区资源和分帧绘制；索引与算路代码使用 Garmin 官方扩展代码分页机制。搜索索引采用前缀压缩。离线路由采用最短路径树、区域连接点和带权 A*，再还原道路曲线。GPS 与轨迹在本地处理。

## 重建与验证

本机需要 Connect IQ SDK 9.2、JDK 19、Python 3；签名使用本机开发密钥，私钥不随包分发。运行 **tools/build.sh** 生成正式 PRG。生成器与测试脚本位于 tools/、tests/。

更新地图前，下载并校验北京 PBF；Python 独立环境安装 **osmium、networkx、scipy、pypinyin**。依次运行：

1. tools/read_pbf.py、tools/pack_map.py
2. tools/build_navigation.py、tools/pack_navigation.py
3. tools/pack_search.py
4. tools/build.sh
5. tools/validate_map.py、tools/validate_navigation.py、tests/test_geometry.py
6. 使用官方模拟器验证查询、路线、内存与保存流程。

导航预处理目前按本次数据中的双向步行路网构建；如果新数据出现单向步行约束，生成器会拒绝按无向路网更新，需先升级算法。测试专用清单有独立应用 ID，固定坐标与画面 **SIM** 标记；测试程序不作为正式 PRG 分发。编译成功不等于真表测试完成。
