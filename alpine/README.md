# 山境 · WristInk Alpine

全屏珠峰主题、大字时间与三栏数据的独立 Garmin Connect IQ 表盘。参考用户提供的 Forester X 展示图的信息层级，以珠峰北壁轮廓创作原创山景；不复用原作品牌或位图。山顶烟雾状飘雪已按用户要求移除。

- **本能系列**：独立重画的深色天空与大块白色雪面，为硬件圆窗独立排版，右上默认显示心率，可切换剩余天数或压力。
- **圆形彩屏**：原生尺寸珠峰、大块雪面、远山与云层，晨、昼、昏、夜四种时段；太阳沿示意轨迹移动，夜间显示近似月相。
- **智能场景**：低电量闪电 → 高压力暖色天空 → 雨天 → 步数达标彩虹/夜间烟花，按此顺序选择。每种也可手动选用。场景是静态插画，不循环播放动画。
- **数据**：底部三栏各可选择步数、心率、总热量、海拔、预计续航天数、距离；有未读通知时显示小型帐篷灯光。
- **时间**：跟随系统或独立 12/24 小时制，秒数仅在唤醒时更新。AMOLED 休眠显示独立低亮时钟。
- **设置**：英文默认、简体中文覆盖；显示单位跟随手表。表盘指标使用紧凑英文缩写。

彩屏背景使用独立的图形资源；黑白版单独设计，使用纯黑/纯白实体雪面，没有灰度转换和密集抖点。正常刷新恢复对应背景区域，秒数与数据更新不会留下黑色擦除块。

## 数据与刷新

心率读取系统当前值，缺失时使用 180 秒内的历史样本；唤醒时每 5 秒检查一次。步数、总热量、电池、海拔与距离按分钟读取。电池显示使用系统 `batteryInDays`：10 天及以上显示整数天，10 天以下保留一位小数；缺失/旧接口显示 `--D`，不从百分比推算。低电量场景仍按设置中的百分比阈值触发。压力仅使用支持设备上 5 分钟内的系统压力历史；海拔历史回退最多 15 分钟。缺失值显示 `--`，零和负海拔有效。

天气每 5 分钟读取 Garmin 缓存，拒绝超过 3 小时或未来的观测。位置仅读取 2 小时内的已有定位，或有效天气的位置；不主动启动 GPS，不发网络请求。官方日出日落 API 存在且位置有效时使用它，否则用 06:00/18:00 作为**画面时段回退**，不把它显示为实际日出日落。太阳位置是弧形示意，不是精确太阳高度角；月相为平均朔望周期近似。

达标效果按 Garmin **步数目标**触发，热量栏是 Garmin 的**总热量**，不是活动热量。天气、压力、手机通知的可用性由设备和同步状态决定。

MIP 休眠按系统分钟节奏更新，不使用持续秒回调。AMOLED AOD 暂停环境/健康读取，只画低亮时间，四个互不重叠的纵向位置逐分钟轮换。此策略不构成实表续航或永久无烧屏承诺。

## 构建与安装

需要 Connect IQ SDK、目标设备包、JDK 19、Python 3 + Pillow，以及个人开发签名密钥 `~/.Garmin/keys/developer_key.der`。SDK 路径读取 Garmin SDK Manager 的 `current-sdk.cfg`。字体与绘图资源从源文件重新生成，不依赖已编译文件。

```sh
# 可用 ALPINE_PYTHON 指定装有 Pillow 的解释器
zsh tools/build.sh live
zsh tools/build.sh preview instinct3solar45mm epix2
zsh tools/build.sh tests instinct2s epix2
python3 tools/scenario.py epix2 9
```

正式安装只使用 `bin/Alpine-<device>-live.prg`：选择与手表对应的目标，USB 连接手表后复制到 `GARMIN/APPS/`，断开后在表盘菜单选择山境。`preview`、`scene`、`tests` 都有独立 ID，仅供验证，演示数据不会进入正式包。

源码目录 `source/`；属性定义 `tools/settings.py`；设备与原生字体生成 `tools/generate.py`。字体为 SIL OFL Rajdhani SemiBold，许可与原始字体保存在 `assets/fonts/`。
