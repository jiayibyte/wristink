# 山境 · WristInk Alpine

全屏珠峰主题、大字时间与三栏数据的独立 Garmin Connect IQ 表盘。参考用户提供的 Forester X 展示图的信息层级，以珠峰北壁轮廓创作原创山景；不复用原作品牌或位图。山顶烟雾状飘雪已按用户要求移除。

- **本能系列**：独立重画的深色天空与大块白色雪面，为硬件圆窗独立排版，右上默认显示天气图标和温度；可在手表端菜单独立改成其他指标。
- **圆形彩屏**：原生尺寸珠峰、大块雪面、远山与云层，晨、昼、昏、夜四种时段；太阳和月亮按位置、时刻分别升落，月亮根据实际月相显示明暗；默认白天只绘制太阳、日落后才绘制月亮；可在「日月显示」选择「真实天象」，允许符合升落条件的日月同辉。
- **智能场景**：低电量/高压力强调色、步数达标彩虹/夜间烟花；天气始终独立影响山景。手动背景还提供独立极光、雨、雪、阴、雾和雷暴，以及四种节日皮肤。场景是静态插画，不循环播放动画。
- **节日主题**：默认按当地日期自动启用春节、中秋、圣诞、万圣节的山色与天空装饰，可在「节日主题」中关闭或手动选择。春节为除夕至初七，中秋为农历八月十五当天，圣诞为 12/24–12/26，万圣节为 10/31。农历采用香港天文台 2020–2040 离线历表；超出范围不猜测农历日期。节日仍保留昼夜、天气和真实月相，且优先于步数达标的彩虹/烟花装饰，避免叠加过密。
- **数据**：顶部、山景侧边、圆窗/天气位、底部三栏可独立替换数据；有未读通知时显示小型帐篷灯光。
- **时间**：跟随系统或独立 12/24 小时制，秒数仅在唤醒时更新。AMOLED 休眠显示独立低亮时钟。
- **设置**：英文默认、简体中文覆盖；显示单位跟随手表。表盘指标使用紧凑英文缩写。

彩色 MIP 使用设备的 64 色调色板，普通白昼为亮蓝天空、白色雪面和冰蓝山脊；不再限制为黑白灰加青色的五色背景。AMOLED 使用独立的全彩渐变资源。黑白版单独设计，使用纯黑/纯白实体雪面，没有灰度转换和密集抖点。正常刷新恢复对应背景区域，秒数与数据更新不会留下黑色擦除块。

## 自定义数据位

进入手表中这款表盘的「设置 / 自定义」菜单，选一个数据位置，再选择想显示的指标；选择后自动保存，按 BACK 返回表盘。入口名称可能随固件语言略有不同。该入口由原生 `getSettingsView` 提供，本地侧载也可使用，不依赖商店网页设置。

菜单内「时间格式」可直接选择跟随系统、12 小时或 24 小时；「日月显示」可选择日夜切换（默认）或真实天象。这两项与手机 Connect IQ 设置同步保存，改时间格式不会重置数据位。日夜切换仍保留真实月相和地平线条件：月亮未升起或接近新月时可能不显示，不用固定满月补画。

「数据区样式」提供四种底部装饰：经典（简洁实心横条）、峰翼（默认，三层侧翼和日期双线）、等高线（切角空心卡片）、远征（斜刻度、菱形节点和底角括线）。手机 Connect IQ 设置也提供相同选项。样式只改变装饰，不改变数据选项；隐藏某一栏会同时隐藏它的装饰。黑白屏采用纯色线条，彩屏颜色跟随山景主题；休眠 AOD 不绘制装饰。

「节日主题」提供自动、关闭、春节、圣诞、万圣节、中秋；手机与手表端均可设置，单独保存，不改变数据位和底部样式选择。春节使用红金山色、双侧烟花、立体灯笼和小旗；圣诞使用冰蓝极光、悬挂彩球和缠绕彩灯的树群；万圣节使用紫橙山色、发光轨迹、蝙蝠群、南瓜与枯枝；中秋使用蓝金山色、金色流云、桂花枝、山间小亭与玉兔。节日场景仍保留原来的昼夜与天气变化。黑白版通过图案区分，不增加灰阶抖点。中秋不强制绘制满月，圣诞不强制下雪。背景每次只加载一张；节日不新增 GPS、网络或秒级计算。素材及日期来源见 `assets/festivals/SOURCES.md`。

本能显示六个可配置位置：圆窗、顶部、山景左侧、底部左/中/右。彩屏额外显示山景右侧；圆窗选项对应彩屏时间左侧的天气位。

可选项：步数、心率、总热量、海拔、系统预计剩余天数、距离、天气/温度、压力、通知数、日出、日落、隐藏。标签、图标与单位随指标同步切换；缺失值显示占位。日出/日落数据位只显示官方接口提供的时间，不把无定位时的画面示意时段当作实际时刻。

默认布局：顶部与山景左/右侧三个数据位隐藏，圆窗/天气位显示天气温度，底部为步数/心率/热量。三个隐藏位仍可在菜单中重新选择指标。升级时仅将旧出厂的海拔/剩余天数/距离组合改为隐藏，保留其他自定义选择；这项迁移只执行一次。底部原有选项编号保持不变。升级时旧默认心率圆窗改为天气；旧版本明确选择的剩余天数/压力圆窗会保留，之后可随时在新菜单替换。

## 背景与天空装饰

「背景皮肤」在手表菜单和 Connect IQ 设置中提供 18 项：自动、黎明、白昼、黄昏、夜晚、雨景、暖色强调、闪电、彩虹、烟花、雪天、阴天、雾天、极光、春节、圣诞、万圣节、中秋。选中即保存为常用背景，返回表盘、关闭菜单或重新启动后仍保持，不需要另外点“设为默认”。现有 0–12 选项编号保持不变。

- 选择「自动」时按昼夜、缓存天气和已有智能场景规则变化，并按「自动模式的节日主题」处理节日；保留旧版本的节日设置。
- 手动选择背景优先于自动节日、低电量、压力和达标场景，日期变化不会把常用极光/雨雪/节日背景换掉。节日可在一年中的任意一天固定使用；节日皮肤仍保留随时间变化的昼夜。
- 「天气联动」默认跟随手表缓存天气。极光、节日等手动皮肤保留所选风格，同时可变化云层、降雨、降雪和能见度；选择「固定所选皮肤」可关闭这些自动天气变化。直接选择雨、雪、阴、雾、闪电时保持该天气插画，不受实际晴天替换。数据位的天气/温度始终使用真实缓存。
- 「天空装饰」默认关闭，可选择飞鸟、飞机、飞鸟与飞机。装饰只在正常山景绘制，位于天空并避开山脊、单色实体圆窗和顶部数据位；云层可以遮住它们。位置按五分钟节奏轻微变化，不新增秒级动画、定位、传感器或网络请求，AMOLED AOD 不绘制。

独立极光是装饰皮肤，不表示实际观测到了极光。太阳、月亮和时间格式沿用用户自己的设置；手动背景不伪造天文升落、健康或天气数据。

## 数据与刷新

心率读取系统当前值，缺失时使用 180 秒内的历史样本；唤醒时每 5 秒检查一次。步数、总热量、电池、海拔与距离按分钟读取。电池显示使用系统 `batteryInDays`：10 天及以上显示整数天，10 天以下保留一位小数；缺失/旧接口显示 `--D`，不从百分比推算。低电量场景仍按设置中的百分比阈值触发。压力仅使用支持设备上 5 分钟内的系统压力历史；海拔历史回退最多 15 分钟。缺失值显示 `--`，零和负海拔有效。

天气每 5 分钟读取 Garmin 缓存，拒绝超过 3 小时或未来的观测。晴天强制零云；多云按云量绘制动态云层，阴雨雪雾同时改变山体色调、积雪或能见度。浓云可遮住日月，雨雪只在对应天气出现，未知天气不伪造降水。位置仅读取 2 小时内的已有定位，或有效天气的位置；不主动启动 GPS，不发网络请求。有有效缓存位置时，使用 SunCalc 1.9.0 的近似太阳/月亮位置算法判断地平线可见性，并参考 Garmin 官方日出日落区间绘制太阳轨迹。时间以 UTC 计算，屏幕轨迹压缩到可用天空，并由山脊遮挡；它不是精确方位角或导航星历。月相由太阳、月亮的位置计算，不再按固定 29 天分组。南纬的月相图标左右翻转，但不模拟精确视场倾角。

没有有效位置时，才使用本地 06:00–18:00 和月相偏移的日月周期作**时段示意**，不把它宣称为真实月出/月落。该回退可能与实际升落不同。表盘不主动开启 GPS；保持手机天气同步或先让手表获得一次定位可恢复基于位置的计算。

天文状态按分钟更新，天气/定位读取有 5 分钟缓存。进入 AMOLED AOD 后停止这些计算和绘制，唤醒时更新。天文公式、BSD 许可证与独立参考样本见 `assets/astronomy/`。

达标效果按 Garmin **步数目标**触发，热量栏是 Garmin 的**总热量**，不是活动热量。天气、压力、手机通知的可用性由设备和同步状态决定。

MIP 休眠按系统分钟节奏更新，不使用持续秒回调。AMOLED AOD 暂停环境/健康读取，只画低亮时间，四个互不重叠的纵向位置逐分钟轮换。此策略不构成实表续航或永久无烧屏承诺。

## 构建与安装

需要 Connect IQ SDK、目标设备包、JDK 19、Python 3 + Pillow，以及个人开发签名密钥 `~/.Garmin/keys/developer_key.der`。SDK 路径读取 Garmin SDK Manager 的 `current-sdk.cfg`。字体与绘图资源从源文件重新生成，不依赖已编译文件。

```sh
# 可用 ALPINE_PYTHON 指定装有 Pillow 的解释器
zsh tools/build.sh live
zsh tools/build.sh preview instinct3solar45mm epix2
zsh tools/build.sh tests instinct2s epix2
python3 tools/scenario.py epix2 9
```

正式安装只使用 `bin/Alpine-<device>-live.prg`：选择与手表对应的目标，USB 连接手表后复制到 `GARMIN/APPS/`，断开后在表盘菜单选择山境。`preview`、`scene`、`tests` 都有独立 ID，仅供验证，演示数据不会进入正式包。

源码目录 `source/`；属性定义 `tools/settings.py`；设备与原生字体生成 `tools/generate.py`。数字采用仓库内 Moke 连续笔画方案衍生的原创轮廓；单色小字使用按像素拟合的字模，彩屏字母使用 SIL OFL Rajdhani SemiBold，许可与原始字体保存在 `assets/fonts/`。AMOLED 字体保留覆盖率抗锯齿，单色输出仅黑白两色。装饰坐标由 `tools/panels.py` 生成 `generated/<device>/PanelDecor.mc`；`tools/preview_panels.py` 输出设计对比图，该图不是模拟器验证证据。

## 商店发布构建

首个公开版本候选为 1.0.0。商店页面提供 28 种文字和本地化横幅，表盘运行时仍仅 `eng` / `zhs`，数据标签保持紧凑英文。`store/localizations.json` 为商店专用，不进入表盘设置或运行时。

```sh
# ALPINE_PYTHON 指向装有 Pillow 的解释器
ALPINE_PYTHON=/path/to/python zsh tools/build_store.sh 1.0.0
python3 tools/check_slot_settings.py instinct3solar45mm instinct2 instinct2s instinct2x fenix7 epix2
```

导出会重建可复现资源，保留区域 API 检查，使用统一代码空间优化，调用 Garmin SDK 验证 IQ 与产品签名。提交前另检查 IQ 中的全部硬件变体、设置与语言，排除演示/测试代码。许可证通知随程序资源保留，运行时不加载。

性能与功耗策略见 [performance.md](docs/performance.md)。商店素材只使用实际模拟器画布，标注演示数据；最终正常堆、常亮/唤醒和新截图已完成原生复核，详见验证记录。编译、模拟器验证、Git 提交、商店提交、审核和公开状态分别记录。
