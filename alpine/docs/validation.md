# 山境验证记录 — 2026-11-03

## 1.1.0 珠峰全屏版

根据用户反馈，最终保留干净锐利的大块雪面：彩屏采用珠峰北壁形态的原创几何插画，远山、云层、冰川与山脊延伸到数据区后；黑白屏单独重画为深色天空和更大的完整白色雪面，不使用灰度转换、密集点阵或照片纹理。两版均移除了用户指出的山顶烟雾状飘雪，右上默认心率与电池预计剩余天数保持不变。所有形态为面向小屏的艺术化重绘，不声明实测地形或摄影复刻。

原生资源逐设备生成，只驻留当前场景。整分钟画背景，秒数/数据刷新只恢复对应的背景区域；不会用纯黑擦除框覆盖全屏插画。AMOLED 采用原生尺寸 PNG 和图形池资源，关闭编译器自动图片抖动；黑白采用明确的黑白调色板。彩色 MIP 限制为稳定的黑白灰/青色，以避免暗部的蓝紫量化伪色。高压力场景改为暖色天空，不把珠峰表现为喷发火山。

六个 SDK 目标正式编译成功。Instinct 2S、Instinct 3 Solar、epix2 各 12 项原生测试通过，新增对背景对象复用、场景切换失效、九种场景实际绘制和背景区域恢复的验证。位图与月相的新绘制路径均执行；后续仅调整 fēnix 的资源调色板，没有改动数据/缓存逻辑。日志 `dist/evidence/*-tests.log`。

重新导出当前 `instinct3-native.png`、`instinct2s-native.png`、`epix2-native.png`、`epix2-night.png` 和 `fenix7-native.png`，均为真实模拟器 framebuffer、演示数据。`preview-everest.png` 展示最终黑白/白昼/夜晚全表盘；黑白 2×最近邻，其余 1×。下文旧版本图形和内存结论只作为历史记录，不代表当前画面已获用户认可。

没有进行实体手表安装、长期耗电、所有地区固件与商店发布验证。AOD 沿用只显示低亮时间的策略，本轮未重复执行已有 AOD 的长时验证。

## 1.0.1 细节修订

按用户红框修订：本能圆窗改为圆形留空，移开相邻太阳并清除矩形清底造成的碎边；主时间字体保持不变。底部增加独立 Label / Metric 字体，按实际墨迹裁去侧边空白、统一数字字宽与基线；整行共同决定是否采用较小字体，不再单独缩小四位数。标签留出上下空白，fēnix 7 按原生字体基线单独校正。夜景烟花避开海拔文字。

所有电池显示使用 `System.getSystemStats().batteryInDays`，按分钟读取。运行时检查字段存在与非负有效值；不支持、null、负值显示 `--D`。10 天及以上取整数天，10 天以下显示一位小数。系统电池百分比只用于已有低电量情景阈值，不用于估算天数；设置中的“电量”选项改名“剩余天数”，属性键保持兼容，圆窗默认仍为心率。

六个 SDK 目标正式编译通过；Instinct 2S / Instinct 3 Solar / epix2 各 11 项原生回归通过，新增系统续航估计缺失字段、null、负值、0、2.5、18.4 天及禁止百分比回填的覆盖。逻辑回归之后仅调整字体尺寸、绘制位置与预览 ID，未改变取值/格式化逻辑。

原生截图重新检查四种画布：176×176、163×156、260×260、416×416，含 AMOLED 夜景。当前 `*-native.png`、`epix2-night.png` 和 `preview-board.png` 为本轮实际模拟器输出、演示数据。四位数默认指标无需降字号：Instinct 3 的文字宽 36px / 可用 37px，2S 为 32 / 33px，fēnix 为 40 / 45px，epix 为 72 / 72px；同一行三项保持同一字体与基线。

本轮不重跑未修改的 AOD 策略；下方 AOD 截图和内存表是 1.0 的历史证据。没有真机续航测试或商店发布。旧效果仍可通过 Git 上一提交查看，不能以测试通过代替用户的视觉接受。

## 1.0 初版历史验证

## 范围

参考为用户提供的 Forester X 宣传截图，只有照片与展示缩略图，没有目标原作的原生 framebuffer。因此采用构图适配，不声明逐像素复刻：原创雪山轮廓、同类大字时间、三栏数据和场景；环形数据改为沿上部弧线布局的横排文字。本能硬件圆窗按用户要求默认心率。字号由字体轮廓针对每个原生分辨率重新生成。

## 构建

Connect IQ SDK 9.2.0 / JDK 19；六个 SDK 目标均正式编译成功：instinct3solar45mm、instinct2、instinct2s、instinct2x、fenix7、epix2。本次是各 SDK 目标默认变体的 PRG 构建，未声称已在所有地区固件运行。`generated/profiles.json` 保留各目标 SDK 区域最低 API 信息。

编译保留 Garmin `Rez.Styles module can't be removed` 优化提示；无编译错误。采用 `-O 0`，没有为减少该警告而改变已验证编译路径。

正式包为 `*-live.prg`；预览与测试有独立 ID，且进一步按设备隔离。已实测同一预览 ID 跨 epix2/fenix7 切换时，模拟器会复用错误尺寸字体；独立 ID 消除了这一异常。未通过删除模拟器其他应用或用户配置解决。

## 原生逻辑回归

Instinct 2S、Instinct 3 Solar、epix2 各 10 项测试全部通过，日志在 `dist/evidence/*-tests.log`：

- 午夜、中午、12/24 小时制与系统设置回退。
- 缺失、过期、未来时间戳；心率无效值。
- 黎明/黄昏边界、缺失太阳事件时的画面回退。
- 智能场景优先级、手动覆盖、关闭智能场景。
- 零值、负海拔、公英制与温度换算、缺失值占位。
- MIP 休眠不画秒、唤醒失效整帧；epix2 不执行该 MIP 专项断言。
- 圆窗默认心率与月相周期范围。

早期测试捕获了旧设备不支持浮点 `%` 的月相异常，已用 `floor` 周期归一修复。测试夹具分别使用新旧 BufferedBitmap API。测试运行器在结果为 PASS 时仍返回退出码 1，本项目根据 SDK 的明确测试结果行判断，并保留原始退出码。

最后一轮测试通过后只做绘图坐标、MIP 颜色量化和预览 ID 隔离，未改变时间/数据/场景选择逻辑；对应画面已重新运行检查。

## AMOLED 低亮

通过官方模拟器 Settings → Display Mode → Always-On 实际进入低亮模式，捕获 `epix2-aod.png`，并恢复 High Power。该帧仅 1,384/173,056 像素点亮，约 0.80%。正常山景与数据栏被清除，时钟低亮显示；代码按实际分钟在四个间距大于字体高度的纵向区域轮换。单帧比例不代表所有时间的最高亮屏率或真机烧屏认证。
