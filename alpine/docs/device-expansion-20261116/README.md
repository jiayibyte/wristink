## 构建检查安排

SDK 的数值联合类型推断曾消耗数分钟；补充绘图辅助函数的数值类型，并明确本来使用双精度常量的天文计算结果类型。完整源码与 fr255s profile 的静态类型检查已通过。相同输入在类型检查1与0下的 PRG 哈希完全一致，见 typecheck-equivalence.json；全变体导出复用已完成的源码检查，不逐变体重复推断。原生测试包含天文参考数值，避免仅根据编译判断数值改动。
