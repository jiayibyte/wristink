# Astronomy source and scope

Position and lunar illumination formulas are ported from SunCalc v1.9.0, copyright Vladimir Agafonkin, BSD-2-Clause.
- https://github.com/mourner/suncalc/blob/v1.9.0/suncalc.js

`suncalc-fixtures.json` was generated by the unmodified pinned JavaScript implementation. Native Monkey C tests compare solar altitude, apparent lunar altitude, lunar phase and illuminated fraction with it.

These are low-precision astronomical approximations for a watch-face illustration, not navigation/observation ephemerides. Valid cached location is required for astronomical horizon visibility; no GPS is started. Without it the app falls back to a local-clock and lunar-phase cycle illustration. Screen coordinates are deliberately compressed into the available sky and occluded by the illustrated mountain skyline, not calibrated compass directions.

The phase drawing flips waxing/waning orientation for southern latitudes; it is not a calibrated parallactic-angle drawing. Sunrise/sunset interval from Garmin is preferred for the solar arc when available; true sky altitude controls horizon visibility including polar day/night.
