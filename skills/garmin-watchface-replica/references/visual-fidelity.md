# 视觉拆解、字体与原生像素

## 视觉约定

建立按区域记录的表：用途、参考截图框、目标原生框、对齐/锚点、字形墨迹高宽、笔画宽度、内边距、层级、动态极值、变化许可。保留原图和裁图路径。表壳文字和刻度通常不是屏幕内容；不要把照片边框、反光或镜头畸变复制到 LCD。

先定主时间的高宽、数字间距、冒号和视觉重量，再定地图/图表与副信息区。不要先塞入全部指标再压缩主时间。照片只能给相对比例时明确不确定性；设备 SDK 几何和真实渲染用于落地像素。

参考本身太密时先尽量忠实复现，另提供克制的优化候选；不能擅自把“复现”改为另一种审美。对“之前好看、现在太轻”的反馈，应回到用户接受的母版和线宽，不能继续叠加锐化滤镜。

## 字体不等于一个字号

分别保存 font family / master、字形 ink bbox、advance、baseline、line box、数字等宽策略。排版按 advance，视觉居中按 ink bbox；尾部空白不计入墨迹中心。日期/天气窗的上下边距必须按真实墨迹而非资源高度判断。

七段、点阵、连续轮廓和系统字体不能互相替代。保留 0 的字腔、4 的开闭口、7 的斜度、1 的头尾、切角和数字宽度。固定标签左对齐与数值右对齐可使用独立锚点，避免 STEP/KCAL 随位数漂移。日出图标与左右时间作为一组测量整体中心。

为每种原生尺寸从母版生成：
- 轮廓字体：按目标像素高度重光栅化，再调整 hinting，不反复缩放旧位图。
- 像素母版：优先整数倍或手工拟合的局部尺度；缩小前检查关键横杠与孔洞。3×5 数字压成 2×4 时 0/8 可能完全相同。
- 汉字：从许可明确的字体生成实际所需字符；不能拉扁位图勉强塞入，也不加载整套 CJK 到运行内存。
- 字体族、字号选项很多时，检查同一帧是否反复加载/淘汰同一字体；缓存数量要由内存与热路径共同决定。

## 抗锯齿分两种情况

**1-bit 屏**：最终只有黑/白。可在构建时高倍采样轮廓，再在目标格点阈值化并校正。平滑来自合理的阶梯节奏、对称轮廓、一致笔画和清楚字腔，不来自最终灰阶。不要对小字抖动；容易像污点。锐化、腐蚀/膨胀不能全局盲用，会改字体重量。

**多色/AMOLED**：能力允许时从原始轮廓生成灰阶边缘，或使用系统可缩放字体/抗锯齿图元。抗锯齿图元 API 不会自动修复已经放大的 1-bit atlas。灰阶增加调色板与内存成本，要用实际原生截图对比可读性和预算。先满足昼间视觉，AOD 的细线是独立模式，不能让正常表盘也变轻。

## 必看的字符与状态

- 数字 0123456789、冒号、负号、度号、单位，以及 10:08 / 11:11 / 23:59。
- 9-9 与 12-31、最长星期、0/8/6/9、最窄与最宽数值。
- --、--D、--:--、负温度、三位心率、大步数、大海拔、超长距离。
- 白底黑字/黑底白字、最低分辨率、实际硬件遮罩。

看 1× 原生尺寸判断可读性，3×/4×最近邻图判断像素结构。最终交付不能只有放大的营销图。比较时固定数据和时刻；字形像素变化率与 ink bbox 只是定位工具，不是美观分数。
