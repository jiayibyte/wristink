# 墨刻设置返回冻结：原生复现与修复

基线：`8a45c58` 中的 Moke 1.2.0 代码。目标：Garmin SDK 9.2、Instinct 2X（API 3.4.3）。测试使用独立 app ID，未操作实体手表。

## 可复现缺陷

Instinct 2/2S/2X 等低内存兼容目标按配置仅提供手机设置，`LegacyPower.settings()` 返回 null。应用的 `getSettingsView()` 却在调用该函数前无条件执行 `_view.suspend()`。由于没有实际菜单可退出，这条路径没有对应的恢复动作，视图保持 suspended，`onUpdate` 直接返回；手机设置回调只调用 invalidate，也不会解除暂停。

原生回归直接调用生产 `InstinctFaceApp.getSettingsView()`，记录返回空菜单后的视图状态。基线实际运行触发 `ASSERTION FAILED`，见 `evidence/moke-legacy-settings-before.log`；对应原始测试见 `evidence/moke-legacy-settings-before-test.mc`。

修复：生成每个兼容目标的 `LegacyPower.HAS_SETTINGS` 能力常量。没有本地菜单时立即返回 null，保留表盘运行状态；有菜单时仍先释放/暂停视图，再构造菜单，保留原内存策略。

回归还检查之后的真实属性写入、生产 onSettingsChanged 回调及值读取。新增独立两进程恢复探针，验证六项设置应用、完整绘制、相同 PRG/ID 的第二次加载，以及隐藏/显示、休眠/唤醒后的恢复。

## 状态边界

该缺陷已被明确复现；不能因此将所有型号、固件和历史 IQ 报错自动归为同因。需要继续完成修复后的原生回归、两进程恢复探针和正式包验证。当前桌面锁定导致原生验证暂停；不把空启动日志计为通过。
