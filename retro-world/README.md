# 寰游时刻 · Retro World 2.0.0

复古世界地图表盘。支持的具体设备以 `dist/device-matrix.json` 和商店兼容列表为准；当前 SDK 筛选出 112 个设备目标、183 个硬件变体和 33 套原生资源配置。排除不满足 API/64 KiB 内存基线的旧机型，保留本能 2/2S、Descent G1 的 API 3.2.7 地区固件兼容路径。

2.0.0 主要变化：

- 按实际屏幕尺寸、形状和本能实体小窗生成资源与坐标，不在手表上缩放整张表盘。
- AMOLED 使用暖白数据窗、青绿色地图、琥珀色点缀；MIP 保留黑白样式。本能 3 圆心按官方设备图向左 1px、向下 2px 校准，钟面内收 2px 防裁切；其他静态区域与 1.2.14 像素一致。
- AMOLED 休眠时只绘制低亮时间轮廓，按分钟移位并轮流熄灭对角像素，避免任何像素连续四分钟点亮。验证覆盖一天全部 1440 个分钟和跨日窗口，按圆屏实际面积计算亮屏占比。
- 地图复用经度计算数组，不再每次为每条纬线创建临时数组；只保留当前皮肤的两张地图资源。
- 心率读数未变时不重复擦写心率窗口；走秒期间不重建地图、不轮询天气。图形缓存失效时自动重绘。
- 显式使用小调色板并关闭无用透明通道；正式包通过构建注解排除基准测试类与诊断入口。

## 构建与核验

```sh
RETRO_PYTHON=/path/to/python3 zsh tools/build_release.sh
python3 tools/build_matrix.py --mode live
python3 tools/build_matrix.py --mode perf --devices instinct3solar45mm venu3 instinct2s
python3 tools/run_probes.py --mode perf --devices instinct3solar45mm venu3 instinct2s
python3 tools/build_matrix.py --mode test --devices instinct3solar45mm venu3 instinct2s
python3 tools/run_probes.py --mode test --devices instinct3solar45mm venu3 instinct2s
```

所有命令在本项目目录执行。模拟器测试需已启动 Garmin Connect IQ Simulator。性能诊断使用独立应用 ID 和示例数据，不进入商店包。模拟器耗时不能代替真实手表的续航测试；编译兼容也不等于每台实表验证。原生运行日志、AOD 像素检查和最终签名包验证记录分别保存于 `bin/`、`dist/` 与 `store/evidence/`。

中英文商店文案、隐私说明、更新说明、兼容列表在 `store/`。不要把示例数值或诊断 PRG 当成用户安装文件。正式商店文件为 `dist/RetroWorld-2.0.0.iq`。

## 1.x 设计历史

适用 **Garmin Instinct 3 Solar 45 / 50 mm**，176×176 单色屏。保留原来的复古字形、主文字字号与布局，时间/秒数/日期沿用原数字微调版。

1.2.14 日出日落改为本能原生表盘的组合样式：日出时间在左，中间为实心半太阳、三束光芒与水平线，日落时间在右，整组中心 x=88。太阳依据[佳明官方表盘图标说明页](https://support.garmin.com/en-US/?faq=agZJiZRjhX2adgWkBVOHI9)原图，逐像素适配为 13×8 单色位图，保留光芒与太阳之间的间隙；不是固件像素资源导出。保持原字体与数据读取逻辑，缺失数据仍显示 --:--，不增加运行时绘图、GPS 或网络调用。

1.2.13 将 STEP 和 KCAL 两行统一从 x=42 起笔，左边缘固定对齐，不随数值位数改变。保持原字形、白框和各自行内的垂直位置。

1.2.12 天气图标采用[佳明官方支持页](https://support.garmin.com/en-US/?faq=kArcrtjkiE55MEYli4FtK9)发布的 inReach Mini 2 单色图标，按比例适配到原 9×9 天气槽。共 13 种：晴日、晴夜、多云、雾、冰雹、少云日、少云夜、雨、雪、雷暴、未知、风、雨雪混合；按手表缓存的天气状态自动切换。晴/少云按缓存日出日落切换昼夜，缺失时用已有位置估算太阳高度，无位置则本地 06–18 时回退。没有新增天气或 GPS 请求。此为官方公开图标的缩制版，并非读取 Instinct 固件私有图标资源。字体、天气窗、地图皮肤、厚重圆盘与抬腕走秒逻辑不变。

1.2.11 按用户“之前更好看、现在太轻”的反馈，圆盘恢复厚重仪表感：黑色外圈按 62px 开孔居中，12 条长时标加 48 条短分钟线；时针恢复 3px、轴心恢复半径 2px。分针、各指针长度、原 12/3/6/9 字形和圈的位置不变。保留不越硬件边界、不超 39×39 缓存及抬腕才走秒的优化。日出日落在 1.2.14 已按官方公开图标及本能原生排布更新。

1.2.10 只优化右上模拟圆盘：取消重复数字外描边，由实体圆形开孔形成边缘；保留 12 条时标，48 条细分短线改为单像素点，原 12/3/6/9 字形不变；时针从 3 像素细为 2 像素，时分针仍保留原 11/16 像素长度和秒针间距，中心轴半径从 2 改为 1。其他数据和字体不动，秒针仍仅抬腕时走动。全部 720 个时分位置验证在原 39×39 缓存内，未增加秒级绘制或灰阶闪烁。单色像素阶梯仍存在；前后图是经过相同开孔遮罩的设计示意，见 `RetroWorld-circle-comparison.png`。

1.2.9 修正日期数字贴上下边界：字格从 8×15 改为 8×13，放在 y=94..106，使白框 y=93..107 内上下各有至少 1 像素白边。通过各删除上下半段的一行直线笔画压紧高度，保留原段头和切角；横杠移到中线 y=100。日期栏边框、星期、水平排布及其他字体不动。全部 10 个数字、4 个位置均已检查，见 `date-padding-validation.json`。

1.2.8 单独校准 STEP、KCAL 的水平与垂直居中。实体圆圈会挡住主屏右侧，按完整 94 像素宽的背景计算中心会偏右；现在参考官方设备图 alpha 遮罩后的可见白框，以及字形墨迹宽度（排除最后一个字符的字距）。STEP 墨迹中心为 (58,35)，KCAL 为 (59,45)，文字顶部为 y=33 / 43；对实际白色可见区域中心的误差均小于半个像素。字体、实体白框和其余数据不变。设计预览也补上这一处硬件遮挡，验证数据见 `status-alignment.json`。

1.2.7 只缩小独立天气窗：白底框 52×17 → 43×13，图标 11×11 → 9×9，温度从 10 像素高改为 8 像素；温度沿用同一套 3×5 原始字母轮廓，在目标大小直接对齐像素生成。白底框仍位于圆圈下方、日期上方；其他字体、16 地图皮肤、定位和抬腕走秒不变。

1.2.6 增加 16 种地图皮肤，包含原复古点阵、旧版实心和极简海岸，以及晨昏和不同天气的日夜纹理。自动读取本版已有缓存定位、佳明天气和日出日落数据；不增加 GPS 或天气接口调用。地图的大陆轮廓和经纬度投影保持一致。

## 地图皮肤自动规则

| 皮肤 | 自动条件 |
|---|---|
| 01 复古点阵 | 晴天白昼 12–14 点，或白昼缺少天气时 |
| 02 旧版实心 | 晴天白昼 10–12 点；与原实心底图像素完全相同 |
| 03 极简海岸 | 晴天其余白昼时间 |
| 04 星夜反显 | 晴天或天气未知的夜间 |
| 05 晨光横纹 | 晴天或未知天气，日出前后约 45 分钟 |
| 06 暮色斜纹 | 晴天或未知天气，日落前后约 45 分钟 |
| 07 白昼云纹 / 08 云夜反显 | 多云的非夜间 / 夜间 |
| 09 细雨点阵 / 10 夜雨斜纹 | 雨天的非夜间 / 夜间 |
| 11 晴雪晶格 / 12 雪夜反显 | 雪、冰雹或雨雪混合的非夜间 / 夜间 |
| 13 轻雾纬线 | 雾、霾或类似低能见度天气 |
| 14 长风流纹 | 大风或类似风况 |
| 15 雷暴线纹 / 16 雷夜反显 | 雷暴天气的非夜间 / 夜间 |

天气优先于晨昏；日夜优先参考定位对应的日出日落，能处理日出日落跨手表本地午夜的情况。无日出日落但有有效位置时用近似太阳高度判断极昼极夜；无位置时按手表本地时间提供晨昏回退。时刻均指手表显示时区。皮肤纹理表达本地天气氛围，不是全球气象分布。

地图还以 UTC 计算世界昼夜区域，在夜间加深底纹，随一天的时间缓慢移动。每五分钟重新组成缓存；天气类别或定位圆点所在像素变化时也会更新。每次只加载当前皮肤的日、夜两张小位图，不把全部 32 张资源放入运行内存。不连续开启 GPS，不增加秒级地图动画，抬腕走秒策略不变。

`RetroWorld-map-skins.png` 是 16 种皮肤总览；`RetroWorld-map-daylight.png` 是复古点阵皮肤在一天四个时段的底纹变化；均为设计示意图。

1.2.5 在素材生成阶段保留原七段轮廓，以更高精度处理端点后转换为最终单色像素，修补取整造成的单像素凹口。日期只补端帽凹口。每个字形改动不超过原墨迹的 5%，笔画连接与字腔数量保持一致；外接框不扩张，孤立突点允许向内收 1 像素。不是更换字体，也不调整粗细或布局。单色硬件仍会有像素阶梯，改善幅度有意保持克制。

`dist/RetroWorld-type-comparison.png` 为原版 / 微调版的设计对照，使用最近邻放大展示真实单色像素，不给预览额外加模糊或灰阶。`dist/typography-validation.json` 保存全部 30 个数字字形的改动量和约束检查。

1.2.3 将 KCAL 热量行从 y=41 下移到 y=42，拉开与上方分隔线的距离。除版本号外，表盘运行代码相对 1.2.2 仅有这一处坐标变化；保留既有字体与抬腕走秒策略。

1.2.4 将底部日出、日落图标及时间整体右移 8 个原生像素，按实际图标与文字占用宽度在 x=88 居中；垂直位置不变。离线预览中的时间对齐也修正为与正式绘制一致。

新增功能：

- 底部删除 ALM / MSG，改为日出、日落图标与 `HH:MM`；时间按选定位置计算，并使用手表本地时区显示。
- 世界地图使用 Natural Earth 真实陆地轮廓和统一经纬度投影，提供复古网格点阵、旧实心等 16 种样式，昼夜区域随时间变化。
- 天气图标和摄氏温度移至右上圆圈下方、日期栏上方的独立小窗，地图内与地图下方不再堆放天气信息。支持晴、云、雨、雪、雷暴、雾、风七类图标，随佳明本地天气缓存变化。
- 地图定位由十字改为小圆环加圆心：黑色主体 5×5、外侧一像素白色衬底。优先使用最近的定位记录；无有效定位时使用天气观测城市的位置。
- 保留 HR 心率、BAT 剩余天数、STEP 今日步数、KCAL 今日热量、ALT 海拔、DIST 今日距离、日期和右上动态模拟表。

将 `dist/RetroWorld-Instinct3.prg` 复制到手表 **GARMIN/APPS**，安全断开后选择 **Retro World**。应用 ID 保持 `d2fd1f269ea4491f9bf5c77046e0e301`，更新既有 Retro World；其他表盘独立。

## 天气、位置和日出日落

- 读取佳明缓存天气，不自行访问外部天气服务器。需要手表已从 Garmin Connect 同步天气；无数据时显示 `WX --C`，不填充演示值。
- 优先使用两小时内且质量有效的定位记录；否则使用三小时内天气观测位置。过期、未来时间、无效经纬度或没有位置时不画十字，不将经纬度 0,0 作为默认位置。
- 地图上一个像素约对应 4° 经度，小圆点只用于世界尺度的近似定位。天气城市位置不等于即时 GPS 位置；表盘不持续开 GPS。
- 可在手表天气小工具完成手机同步，或在手表获得一次有效定位后回到表盘查看。
- 日出日落调用 Garmin `Weather.getSunrise/getSunset`；无有效位置或极昼极夜等无法计算的情况显示 `--:--`。显示的是手表设置时区的时间。
- 不在日志中记录原始经纬度。定位与地图计算在手表本地完成。

API：[天气缓存](https://developer.garmin.com/connect-iq/api-docs/Toybox/Weather/CurrentConditions.html)、[位置](https://developer.garmin.com/connect-iq/api-docs/Toybox/Position/Info.html)、[日出日落](https://developer.garmin.com/connect-iq/api-docs/Toybox/Weather.html)。

## 抬腕走秒与节电

- 数字秒数和右上秒针改为只在抬腕唤醒、或返回表盘的活动显示期间走动。
- 系统进入低功耗后，两者停留在最后显示的秒数与位置；下一次抬腕立即跳到当前秒数并继续每秒走动。
- 待机仍按分钟更新时分、日期和其他指标；整帧更新时恢复同一个冻结秒数和秒针位置，不会把秒数跳成 00。
- 不再实现自定义 `onPartialUpdate`，取消待机时应用的秒级绘制。唤醒持续时长由手表系统管理。

- 保留原复古位图字形与布局，文字资源不变；数字只做离线栅格修边，设备依旧绘制同样尺寸的单色位图。高精度采样不在手表上运行，不增加刷新频率。
- 天气与上次定位正常每 5 分钟读取一次；抬腕刷新至少间隔 1 分钟。日出日落只在日期或位置缓存键变化时重算。
- 地图组成结果缓存为 89×29 位图，以五分钟时间段、天气类别或定位点像素变化作为失效条件；每分钟绘制表盘时直接复制缓存。经纬度三角函数预计算，夜间以连续行区间复制位图。
- 唤醒期间，秒针端点预计算，圈内时分针使用 39×39 缓存。每秒仅恢复旧秒针小矩形、画新秒针（各最多 21×21）和改变的秒数字形（13×24）；十位仅在变化时刷新。
- 待机状态的重复更新不会读取心率，也不会改写秒数或秒针。天气、定位和日出日落继续沿用低频缓存。
- 心率抬腕时最多每 5 秒读取，日常指标按分钟更新。BAT 直接取佳明 `batteryInDays`，如 `24.3D` 表示预计 24.3 天；无数据为 `--D`。

## 重建

需要 Connect IQ SDK 9.2、JDK 19、带 Pillow 的 Python。签名私钥从本机读取，不随包分发。

```sh
cd retro-world
zsh tools/build.sh
monkeyc -f tests/test.jungle -d instinct3solar45mm -o bin/RetroWorld-tests.prg -y "$HOME/.Garmin/keys/developer_key.der" -t -w
monkeydo "$PWD/bin/RetroWorld-tests.prg" instinct3solar45mm -t
```

`tools/assets.py` 生成地图、图标与离线预览；`tools/retro_style.py` 保留原版文字和数字生成器。静态像素资源先生成后再编译，不在手表上生成字体或解析 GeoJSON。
